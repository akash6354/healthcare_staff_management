# API

Base: `/api/v1`. JSON. OpenAPI generated by FastAPI at `/api/v1/openapi.json` (disabled in production for anonymous users).
Typed TS client generated from OpenAPI into `packages/api-client`.

Conventions
- Auth: `Authorization: Bearer <access JWT>` (≤15 min). Refresh token in an `HttpOnly; Secure; SameSite=Strict` cookie scoped to `/api/v1/auth/refresh`, with a CSRF double-submit token on cookie routes.
- Every route declares `permission` and `scope` (see `security.md` §3). A missing declaration fails a CI test.
- Lists are cursor-paginated: `?cursor=&limit=` (max 100). Filters are query params.
- Errors: `{ "error": { "code": "TASK_INVALID_TRANSITION", "message_key": "errors.task.invalid_transition", "details": {} } }`. The UI translates `message_key`.
- Mutations accept `Idempotency-Key` (required for PWA outbox routes).
- Rate-limited routes are marked ⏱.

Scope shorthand: **H** hospital-wide · **D** user's department(s) · **A** user's areas/zones · **S** self (assignee/requester) · **V** own vendor · **P** platform.

## Auth
| Method & path | Permission / scope | Notes |
|---|---|---|
| POST `/auth/otp/request` ⏱ | public | `{hospital_code, email}`. Always returns 202 (no account enumeration). Rate limited by email + IP. |
| POST `/auth/otp/verify` ⏱ | public | `{challenge_id, code}` → tokens. 5 attempts, then lockout with backoff. |
| POST `/auth/password/login` ⏱ | public | Admin/manager/vendor. Returns `totp_required` when 2FA is on. |
| POST `/auth/totp/verify` ⏱ | public (pending session) | |
| POST `/auth/totp/enroll` · `/auth/totp/confirm` | self | Required for admin/manager roles before any other route. |
| POST `/auth/pin/login` ⏱ | public + registered device header | `{device_key, employee_code, pin}` |
| POST `/auth/refresh` | cookie | Rotation; reuse → revoke the whole session family. |
| POST `/auth/logout` · GET `/auth/sessions` · DELETE `/auth/sessions/{id}` · POST `/auth/sessions/revoke-all` | self | |
| POST `/auth/password/change` | self | Revokes other sessions. |

## Platform (Oglos staff, separate auth)
`/platform/hospitals` (create from template pack, suspend), `/platform/hospitals/{id}/modules`, `/platform/health`. Scope **P** uses the `oglos_platform` DB role, and every call is audited.

## Tests per endpoint (CI-enforced)
1. Happy path. 2. Missing permission → 403. 3. **Cross-tenant:** a token for hospital B against a hospital A resource id → 404 (never 403, so ids don't leak) for read, list, update, delete and file URLs. 4. Validation errors → 422 with a `message_key`.
